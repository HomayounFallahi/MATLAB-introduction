# Introduction to MATLAB

A complete, self-contained introductory course on MATLAB designed for Chemical Engineers.

**Author:** Homayoun Fallahi  
**Date:** August 2026

## Course Overview

This repository contains 16 progressive lectures that take you from the MATLAB environment and basic syntax all the way to solving realistic chemical-engineering problems. The material is written for undergraduate and early graduate students in chemical engineering (and related fields) who need a practical, engineering-oriented introduction to scientific computing with MATLAB.

## How to Use This Material

- Work through the lectures in order.
- Each lecture contains explanations, MATLAB code examples, and learning objectives.
- Lecture 16 focuses on translating typical chemical-engineering problems (material balances, energy balances, kinetics, reactor calculations, experimental data analysis, etc.) into well-structured MATLAB codes.

## Requirements

- MATLAB (Desktop or Online) – any recent version is fine.
- Optional: VS Code + MATLAB extension (covered in Lecture 15).
