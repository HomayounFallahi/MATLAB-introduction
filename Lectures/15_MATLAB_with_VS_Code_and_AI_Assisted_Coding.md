## MATLAB in VS Code

### What is VS Code?

**Visual Studio Code** is a free, lightweight source-code editor developed by Microsoft. It runs on Windows, macOS, and Linux, and supports virtually every programming language through extensions.

For MATLAB, VS Code offers:

- **Syntax highlighting** — recognizes MATLAB code structure and colors it intelligently
- **Code completion** — suggests function names and variable completions as you type
- **Integrated terminal** — run MATLAB directly from the editor
- **Debugging tools** — set breakpoints and inspect variables
- **Extensions marketplace** — access community and official MATLAB tools

### Setting Up MATLAB in VS Code

#### Step 1: Install VS Code

Download and install VS Code from [code.visualstudio.com](https://code.visualstudio.com).

#### Step 2: Install MATLAB Support Extension

1. Open VS Code.
2. Press `Ctrl+Shift+X` (or `Cmd+Shift+X` on macOS) to open the Extensions panel.
3. Search for `"MATLAB"`.
4. Install the official **MATLAB** extension provided by MathWorks.

You may also install community extensions such as:
* **GitHub Copilot** (optional but recommended)
* **Rainbow CSV** (by *mechatroner*): Highlights columns in CSV/TSV files with distinct colors and supports running SQL queries on tabular data.
* **Spreadsheet Viewer** (by *MESCIUS*): Provides an interface to view and edit XLSX spreadsheets and CSV files directly inside VS Code.
* **vscode-pdf** (by *tomoki1207*): Allows displaying and viewing PDF files natively within VS Code.


#### Step 3: Configure MATLAB Executable Path

For VS Code to run MATLAB, it needs to know where the MATLAB executable is located.

1. Open VS Code settings: `Ctrl+,` (or `Cmd+,`).
2. Search for `"matlab"`.
3. Set the **MATLAB: Engine Path** or **MATLAB: Executable** to point to your MATLAB installation.

Example paths:

- **Windows:** `C:\Program Files\MATLAB\R2024a\bin\matlab.exe`
- **macOS:** `/Applications/MATLAB_R2024a.app/bin/matlab`
- **Linux:** `/usr/local/MATLAB/R2024a/bin/matlab`

### Working with Scripts and Functions in VS Code

#### Running a Script

**Scripts** contain a sequence of commands executed in order. They share the workspace.

```matlab
% reactor_design.m
% Script to calculate reactor volume for a given conversion

% Input parameters
F_A0 = 10;          % Feed rate of A, mol/s
X_A = 0.85;         % Target conversion
r_A = -0.5;         % Reaction rate, mol/(L·s)
C_A0 = F_A0 / 100;  % Initial concentration, mol/L (assume 100 L/s feed)

% Calculate required volume
V_required = F_A0 * X_A / (-r_A * C_A0);

% Display result
fprintf('Reactor volume required: %.2f L\n', V_required);
```

**To run this script in VS Code:**

1. Open the file.
2. Press `Ctrl+Shift+P` and select **"MATLAB: Run Script"**, or
3. Use the keyboard shortcut (configured in settings).

The script executes in the MATLAB engine, and output appears in the terminal or MATLAB Command Window.

#### Running a Function

**Functions** are reusable code blocks with inputs and outputs. They do not share the workspace with the calling script.

```matlab
% antoine.m
% Calculate saturation vapor pressure using the Antoine equation

function P_sat = antoine(T, A, B, C)
    % Input:
    %   T    - Temperature (°C)
    %   A, B, C - Antoine coefficients
    % Output:
    %   P_sat - Saturation vapor pressure (bar)
    
    P_sat = 10.^(A - B ./ (C + T));
end
```

To call this function from another script:

```matlab
% run_antoine.m
T = 80;           % Temperature, °C
A = 3.92931;      % Water Antoine coefficients
B = 1149.26;
C = 226.65;

P_sat = antoine(T, A, B, C);

fprintf('At T = %d °C, P_sat = %.4f bar\n', T, P_sat);
```

Save both files in the same folder, then run `run_antoine.m`.

## Using AI for MATLAB Programming

### Understanding the Potential and Limitations

AI assistants like Claude, ChatGPT, and Copilot can significantly speed up MATLAB programming. However, they are **language models**, not MATLAB compilers. They can:

- Explain MATLAB syntax
- Generate working code for straightforward tasks
- Help debug logical errors
- Suggest optimization strategies
- Guarantee correct code (errors still occur)
- Know every edge case
- Always use the most efficient approach
- Generate real function names (hallucinations happen)

### Use Case 1: Explaining MATLAB Syntax

**Scenario:** You encounter unfamiliar syntax and want to understand it quickly.

**Prompt to AI:**

```
Explain what this MATLAB code does:

A = [1 2 3; 4 5 6];
[m, n] = size(A);
B = reshape(A, n, m);

What is the final shape of B?
```

**Why this works:** AI excels at explaining existing code. The explanation is verifiable by running the code yourself.

### Use Case 2: Generating Code from Pseudocode

**Scenario:** You have a chemical engineering algorithm in pseudocode and want a MATLAB implementation.

**Prompt to AI:**

```
I need to calculate the conversion in a CSTR. Here is the algorithm:

1. Read reactor volume V, inlet concentration C_A0, inlet flow rate F, 
   and reaction rate constant k
2. Calculate residence time tau = V / F
3. Calculate conversion X_A using: X_A = 1 / (1 + k * tau)
4. Display the result

Please write a MATLAB function that implements this algorithm. 
The function should accept V, C_A0, F, and k as inputs 
and return X_A as output.
```

**Expected AI response (example):**

```matlab
function X_A = cstr_conversion(V, F, k)
    % Calculate conversion in a CSTR
    % Inputs: V (reactor volume, L), F (flow rate, L/s), k (rate constant, 1/s)
    % Output: X_A (conversion, dimensionless)
    
    tau = V / F;           % Residence time
    X_A = 1 / (1 + k * tau);
    
end
```

**Important:** Verify the formula before using it. Does `X_A = 1 / (1 + k * tau)` match your engineering textbook? If yes, proceed. If unsure, verify with a reference.

### Use Case 3: Converting Between Programming Languages

**Scenario:** You have working Python code but need MATLAB.

**Prompt to AI:**

```
Convert this Python code to MATLAB:

import numpy as np

T = np.array([300, 310, 320, 330, 340])
P = np.array([1.0, 1.5, 2.1, 2.8, 3.7])

fit = np.polyfit(T, P, 2)
poly = np.poly1d(fit)

T_new = np.linspace(300, 340, 50)
P_new = poly(T_new)

plt.plot(T, P, 'o', T_new, P_new)
plt.show()
```

**Typical AI response:**

```matlab
T = [300 310 320 330 340];
P = [1.0 1.5 2.1 2.8 3.7];

fit = polyfit(T, P, 2);

T_new = linspace(300, 340, 50);
P_new = polyval(fit, T_new);

plot(T, P, 'o', T_new, P_new)
```

**Verification:** Run both versions and compare outputs.

### Use Case 4: Debugging with AI

**Scenario:** Your MATLAB code produces unexpected results.

**Prompt to AI:**

```
I get the wrong result when running this code:

C_A0 = 1.0;   % mol/L
k = 0.5;      % 1/s
t = [0 1 2 3 4 5];

C_A = C_A0 * exp(-k * t);

disp(C_A)

I expect concentrations to decrease, but some values are increasing. 
What is wrong?
```

**AI might respond:**

```
The code looks correct. Concentrations should decrease monotonically 
with time. Let me check the calculation:

exp(-0.5 * 0) = 1.0        → C_A = 1.0 
exp(-0.5 * 1) = 0.6065     → C_A = 0.6065 
...

The math is correct. The issue might be:
1. Are you assigning the result to the right variable?
2. Is there a typo in the exponent (should be -k*t, not +k*t)?

Try: C_A = C_A0 * exp(-k .* t);  (note the .* for element-wise multiplication)
```

You then test the suggested fix and verify it works.

### Use Case 5: Code Optimization

**Scenario:** Your code runs slowly.

**Prompt to AI:**

```
My code calculates a large matrix of reaction rates. 
It uses nested for loops and takes 30 seconds. 
Can you suggest a faster MATLAB approach?

for i = 1:length(T)
    for j = 1:length(C)
        r_A(i,j) = k * C(j)^0.5 * exp(-E_a / (R * T(i)));
    end
end
```

**AI might suggest vectorization:**

```matlab
% Vectorized version
% Expand T to a column vector, C to a row vector
T_col = T(:);           % Column vector
C_row = C(:)';          % Row vector

r_A = k * C_row.^0.5 .* exp(-E_a ./ (R * T_col));
```

**You should:** Test both versions, confirm the vectorized version produces identical results, and measure the speed improvement.

## Responsible AI-Assisted Programming

### Critical Practice 1: Always Verify Generated Code

**Never copy-paste AI-generated code directly into your engineering analysis without verification.**

#### Verification Checklist

- Does the code syntax match MATLAB rules?
- Are all function names spelled correctly?
- Can I look up the function in MATLAB documentation?
- Do the variable names make sense?
- Are dimensions compatible (vectors, matrices)?
- Does the algorithm match the intended logic?
- **Do I understand every line?**
- Have I tested it on a simple example with a known answer?

#### Example: Verification by Hand

**AI generates this code for calculating Antoine vapor pressure:**

```matlab
function P_sat = antoine(T, A, B, C)
    P_sat = 10.^(A - B / (C + T));
end
```

**Manual verification:**

- Is `10.^()` a real MATLAB function? Yes, it computes 10 raised to a power.
- Is the formula correct? Antoine equation: $\log_{10} P_{sat} = A - \frac{B}{C + T}$. The code matches.
- Test with known values for water at 100°C:
  - $A = 3.92931, B = 1149.26, C = 226.65$
  - Expected $P_{sat} \approx 1.0$ bar (atmospheric pressure)
  - `antoine(100, 3.92931, 1149.26, 226.65)` should return ~1.0

Run it. If the result is approximately 1.0, the code is verified.

### Critical Practice 2: Identify Hallucinated Functions

AI models sometimes invent function names that sound plausible but don't exist in MATLAB.

#### Common Hallucinations

| Hallucinated Name | Real MATLAB Function |
|---|---|
| `vec()` | `reshape()` or just direct indexing |
| `norm2()` | `norm()` |
| *`sigmoid()` | *Not built-in; define it yourself or use `1 / (1 + exp(-x))` | 
| `matrix_mult()` | `*` (for matrices) or `.*` (element-wise) |
| `froot()` | `fzero()` or `fsolve()` |

*: EVEN THIS LINE IS HALLUCINATED. MATLAB does have a built-in `sigmoid()` function. But it only applies the sigmoid operation to dlarray data.

#### How to Detect Hallucinations

If AI suggests a function you've never heard of:

1. **Search MATLAB documentation:** Type the function name into the MATLAB Command Window or search the online documentation.
2. **Test it:** Try running `help function_name`. If MATLAB returns "Undefined function," the function doesn't exist.
3. **Ask AI again:** Prompt the AI with "Is `sigmoid()` a built-in MATLAB function?" AI will often acknowledge it and suggest alternatives.

#### Example Scenario

AI generates:

```matlab
y = sigmoid(x);
```

You run this and get:

```
Incorrect number or types of inputs or outputs for function sigmoid.
```

**Correct action:**

1. Recognize the error.
2. Replace with the mathematical definition:

```matlab
y = 1 ./ (1 + exp(-x));
```

3. Verify with a test value:

```matlab
x = 0;
y = 1 / (1 + exp(-x));  % Should be 0.5
```

### Critical Practice 3: Check Numerical Correctness

AI can generate syntactically correct code that produces mathematically incorrect results.

#### Strategy: Compare Against a Reference

For any engineering calculation, compare against:

- **Known values** — use hand-calculated results
- **Benchmark data** — published experimental or simulation results
- **Limiting cases** — check boundary conditions
- **Dimensional analysis** — verify units

#### Example: Material Balance

AI generates code for a binary stream mixer:

```matlab
function C_mix = binary_mixer(C1, C2, F1, F2)
    % Mix two streams
    % C1, C2 - inlet concentrations (mol/L)
    % F1, F2 - inlet flow rates (L/s)
    
    C_mix = (C1 * F1 + C2 * F2) / (F1 + F2);
end
```

**Verification by hand:**

Mass balance on component A:
- Stream 1: $F_1 C_1$
- Stream 2: $F_2 C_2$
- Mixed stream: $(F_1 + F_2) C_{mix}$
- Balance: $(F_1 + F_2) C_{mix} = F_1 C_1 + F_2 C_2$
- Solve: $C_{mix} = \frac{F_1 C_1 + F_2 C_2}{F_1 + F_2}$ 

**Test with simple values:**

```matlab
C1 = 1.0;  C2 = 3.0;  F1 = 1.0;  F2 = 1.0;
C_mix = binary_mixer(C1, C2, F1, F2);
% Expected: (1*1 + 3*1) / (1+1) = 2.0
disp(C_mix);  % Should print 2.0
```

If the result matches, the code is correct for this case. Test additional cases (e.g., unequal flow rates) to be thorough.

### Critical Practice 4: Test Edge Cases

AI-generated code may fail on edge cases or unusual inputs.

#### Common Edge Cases

- **Zero or very small numbers:** Does the code divide by zero? Does it handle near-zero values?
- **Negative numbers:** Are they physically valid for your problem?
- **Empty arrays:** What happens if you pass an empty vector?
- **Large numbers:** Does the code overflow?
- **Mixed data types:** Does the code handle both integers and floating-point numbers?

#### Example: Conversion Calculation

AI generates:

```matlab
function X = conversion(F_A0, F_A)
    % Calculate conversion
    X = (F_A0 - F_A) / F_A0;
end
```

**Edge case test:**

```matlab
% Normal case
X = conversion(10, 2);  % Should be 0.8 

% Edge case: complete reaction
X = conversion(10, 0);  % Should be 1.0 

% Edge case: no reaction
X = conversion(10, 10);  % Should be 0.0 

% Edge case: F_A > F_A0 (unphysical, but should not crash)
X = conversion(10, 15);  % Returns -0.5 (negative conversion)
% Is this handled correctly? In your process, should this be an error?
```

If the code behaves unexpectedly for any case, add error checking:

```matlab
function X = conversion(F_A0, F_A)
    if F_A0 <= 0
        error('F_A0 must be positive');
    end
    if F_A < 0 || F_A > F_A0
        warning('F_A should be between 0 and F_A0');
    end
    X = (F_A0 - F_A) / F_A0;
end
```

## AI as a Programming Assistant Rather Than a Substitute

### The Critical Distinction

AI is a **tool that enhances your capabilities**, not a **replacement for your understanding**.

Consider three scenarios:

#### Scenario A: Inappropriate Reliance on AI

```
Student: "Write code to design a distillation column."
AI: [Generates 300 lines of complex code]
Student: [Copies code, submits without understanding]
Result: Student learns nothing. Code may be wrong. Academic integrity issue.
```

#### Scenario B: Appropriate Use of AI

```
Student: "I need to calculate bubble-point temperatures using the Rachford-Rice equation. 
Can you explain the algorithm?"
AI: [Explains the iterative solution approach clearly]
Student: [Understands the method, writes code themselves, validates against a reference]
Result: Student learns, code is correct, understanding is deep.
```

#### Scenario C: Balanced AI Assistance

```
Student: "I've written code for stage-by-stage distillation calculations, 
but it's running very slowly. Can you suggest optimizations?"
AI: [Suggests vectorization and preallocation]
Student: [Implements suggestions, verifies results match original, measures speedup]
Result: Student learns optimization techniques, code is improved, independence is maintained.
```

### Best Practices for Balanced AI Use

| Do | Don't |
|---|---|
| Ask AI to **explain** concepts | Copy entire solutions without understanding |
| Use AI to **brainstorm** approaches | Rely on AI for critical decisions without verification |
| Ask AI for **syntax help** | Treat AI answers as authoritative without checking |
| Use AI to **optimize** code you've written | Use AI to write code for concepts you haven't learned |
| **Verify** AI suggestions independently | Submit AI-generated work as your own |
| **Test** code on simple, verifiable examples | Trust AI outputs without testing |

## Worked Example: AI-Assisted Material Balance Calculation

### Problem

Design a chemical reactor mixing system. You have three inlet streams:

- **Stream 1:** Component A concentration $C_{A1} = 2.0$ mol/L, flow rate $F_1 = 5$ L/min
- **Stream 2:** Component A concentration $C_{A2} = 5.0$ mol/L, flow rate $F_2 = 3$ L/min
- **Stream 3:** Component A concentration $C_{A3} = 0.5$ mol/L, flow rate $F_3 = 2$ L/min

Calculate the mixed outlet concentration $C_{A,out}$.

### Engineering Approach

**Component balance on A:**

$$F_1 C_{A1} + F_2 C_{A2} + F_3 C_{A3} = (F_1 + F_2 + F_3) C_{A,out}$$

**Solve for outlet concentration:**

$$C_{A,out} = \frac{F_1 C_{A1} + F_2 C_{A2} + F_3 C_{A3}}{F_1 + F_2 + F_3}$$

### AI-Assisted Implementation

**Prompt to AI:**

```
I need to write MATLAB code for a three-stream mixer. 
The inlet concentrations are C_A1=2, C_A2=5, C_A3=0.5 mol/L.
The flow rates are F_1=5, F_2=3, F_3=2 L/min.

Calculate the outlet concentration using a material balance.
Include comments and display the result with proper units.
```

**AI Response (example):**

```matlab
% Three-Stream Mixer Material Balance
% Component A balance

% Inlet conditions
C_A1 = 2.0;      % Component A concentration in stream 1 (mol/L)
C_A2 = 5.0;      % Component A concentration in stream 2 (mol/L)
C_A3 = 0.5;      % Component A concentration in stream 3 (mol/L)

F_1 = 5;         % Flow rate of stream 1 (L/min)
F_2 = 3;         % Flow rate of stream 2 (L/min)
F_3 = 2;         % Flow rate of stream 3 (L/min)

% Calculate inlet molar flow rates
n_A1 = C_A1 * F_1;
n_A2 = C_A2 * F_2;
n_A3 = C_A3 * F_3;

% Total molar flow rate of A
n_A_total = n_A1 + n_A2 + n_A3;

% Total outlet flow rate
F_total = F_1 + F_2 + F_3;

% Outlet concentration
C_A_out = n_A_total / F_total;

% Display results
fprintf('Stream 1: F=%.1f L/min, C_A=%.2f mol/L, n_A=%.2f mol/min\n', F_1, C_A1, n_A1);
fprintf('Stream 2: F=%.1f L/min, C_A=%.2f mol/L, n_A=%.2f mol/min\n', F_2, C_A2, n_A2);
fprintf('Stream 3: F=%.1f L/min, C_A=%.2f mol/L, n_A=%.2f mol/min\n', F_3, C_A3, n_A3);
fprintf('\n');
fprintf('Total molar flow of A: %.2f mol/min\n', n_A_total);
fprintf('Total volumetric flow: %.1f L/min\n', F_total);
fprintf('Outlet concentration: %.4f mol/L\n', C_A_out);
```

### Verification

**Step 1: Check the algorithm.**

The code implements the material balance correctly:

$$n_{A,total} = C_{A1} F_1 + C_{A2} F_2 + C_{A3} F_3$$

$$C_{A,out} = \frac{n_{A,total}}{F_{total}}$$

**Step 2: Hand calculation.**

$$n_{A1} = 2.0 \times 5 = 10 \text{ mol/min}$$
$$n_{A2} = 5.0 \times 3 = 15 \text{ mol/min}$$
$$n_{A3} = 0.5 \times 2 = 1 \text{ mol/min}$$
$$n_{A,total} = 10 + 15 + 1 = 26 \text{ mol/min}$$
$$F_{total} = 5 + 3 + 2 = 10 \text{ L/min}$$
$$C_{A,out} = \frac{26}{10} = 2.6 \text{ mol/L}$$

**Step 3: Run the MATLAB code and compare.**

```
Stream 1: F=5.0 L/min, C_A=2.00 mol/L, n_A=10.00 mol/min
Stream 2: F=3.0 L/min, C_A=5.00 mol/L, n_A=15.00 mol/min
Stream 3: F=2.0 L/min, C_A=0.50 mol/L, n_A=1.00 mol/min

Total molar flow of A: 26.00 mol/min
Total volumetric flow: 10.0 L/min
Outlet concentration: 2.6000 mol/L
```

**Result:**  The code and hand calculation match perfectly.

### Engineering Interpretation


AI might suggest `ode45`, but if you need a **symbolic solution** (not numerical), that's wrong.

**Why it happens:** AI generates plausible-sounding names.

**Solution:** Immediately test any function you're unfamiliar with. If it fails, search MATLAB documentation or ask AI: "Is `norm2()` a built-in MATLAB function?"

## Solution

### Concept

This is a **steady-state mass balance** on a mixing unit. For any component, the sum of inlet masses equals the outlet mass:

$$\text{Mass in} = \text{Mass out}$$

For component A:

$$F_1 \cdot wA_1 + F_2 \cdot wA_2 = (F_1 + F_2) \cdot wA_{out}$$

Solving for the outlet weight fraction:

$$wA_{out} = \frac{F_1 \cdot wA_1 + F_2 \cdot wA_2}{F_1 + F_2}$$

This is the composition-weighted average of the inlet streams.

### Idea

1. Calculate the mass of component A in each inlet stream.
2. Sum the masses to get total component A.
3. Divide by total outlet flow to get the outlet weight fraction.
4. Test the function with given data and an edge case.
